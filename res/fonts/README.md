# Helvetica Neue Bold

`HelveticaNeue-Bold.woff2` is the self-hosted font used by this portfolio, included under the site owner's confirmed licence for this use.

The WOFF2 contains the original font's full glyph set and embedded copyright metadata. The original TTF is not included.

Helvetica Neue is proprietary, not an open-source font. This repository grants no additional rights to the font; reuse or redistribution requires appropriate permission from its rights holder.
